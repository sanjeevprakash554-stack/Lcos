📖 Meta for Developers WhatsApp Cloud API Setup Guide

Quick Start: Follow these 4 steps in your Meta for Developers dashboard to connect your WhatsApp Business number to LCOS.

Step 1: Create Meta Developer App

  1. Go to developers.facebook.com and sign in.
  2. Click My Apps > Create App.
  3. Choose Other > Select Business as the app type.
  4. Fill in your App Name (e.g. LCOS Logistics) and complete app creation.

Step 2: Add WhatsApp & Copy Credentials

  1. On the App Dashboard, find WhatsApp and click Set up.
  2. Navigate to WhatsApp > API Setup on the left sidebar.
  3. Copy the Phone Number ID and paste it into LCOS.
  4. Copy the WhatsApp Business Account ID and paste it into LCOS.
  5. Copy the Temporary Access Token (or create a permanent System User Token under Business Settings with whatsapp_business_messaging permission).

Step 3: Configure Inbound Webhooks

  1. In Meta Dashboard, go to WhatsApp > Configuration.
  2. Under Webhook, click Edit.
  3. Callback URL: https://<your-domain>/api/whatsapp/webhook (use ngrok for local testing, e.g. https://xxx.ngrok-free.app/api/whatsapp/webhook).
  4. Verify Token: lcos_meta_verify_token_2026 (matches LCOS setting).
  5. Click Verify and Save.
  6. Under Webhook fields, click Manage and click Subscribe next to messages.

Step 4: Test Real Messages

  1. In API Setup, add your own WhatsApp phone number to the "To" recipient list to receive test messages.
  2. Send a test message from the LCOS WhatsApp Hub console!
